# 🇬🇷 Projeto Grego

Aplicação web interativa criada para auxiliar no estudo da língua grega moderna em nível A1.

O projeto reúne conteúdos, atividades e recursos interativos para tornar o aprendizado do grego mais prático e dinâmico.

## ✨ Funcionalidades

* 📚 Conteúdos de estudo em nível A1
* 🧠 Flashcards para memorização
* ✍️ Atividades de construção de frases
* 📝 Quizzes e exercícios
* 🔊 Pronúncia das palavras por áudio
* ⭐ Marcação de palavras para revisão
* 📊 Acompanhamento do progresso de estudo
* 📅 Palavra do dia
* 📱 Interface adaptada para diferentes tamanhos de tela

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Web Speech API

## 🎯 Objetivo

O projeto foi desenvolvido como uma forma de unir o aprendizado da língua grega com a prática de desenvolvimento web.

Além de servir como ferramenta de estudo, o projeto também representa uma oportunidade de praticar conceitos de:

* desenvolvimento de interfaces;
* lógica de programação;
* manipulação de elementos da página;
* JavaScript;
* organização de conteúdos;
* criação de aplicações interativas.

1. Faça o download ou clone este repositório.
